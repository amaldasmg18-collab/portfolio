Projects

SOC Log Analyzer

Portfolio project

A Django web app for uploading authentication logs, detecting suspicious activity and triaging alerts. It parses logs into structured events and applies five explainable, configurable detection rules, including brute force, password spraying patterns and success after repeated failures.

  • Log Explorer with filters, sorting and CSV export
  • Alert workflow: Open, Investigating, Resolved, False Positive, with notes
  • Dashboard and reports built from the stored data
  • Upload validation, CSRF protection and login required on every page
  • Python
  • Django
  • SQLite
  • Bootstrap
  • Chart.js

It demonstrates log analysis and detection fundamentals. It is not a replacement for a production SIEM, and it hasn't been used in a real SOC.
